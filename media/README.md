# Reel HUNINN Android

- `huninn-android-reel.mp4`: 25 s, 1080×1920, H.264 + AAC; cerca de 2,1 MB.
- `capa.jpg`: capa vertical.
- `legenda.txt`: texto sugerido para Instagram.
- `preview.jpg`: sequência de cenas ilustrativas.

No GitHub, abra o arquivo e escolha **Download raw file**. Alternativamente,
baixe o ZIP do repositório e extraia esta pasta no celular.

Animações de terminal ilustrativas, com trilha sintetizada original. Não contém
música de terceiros nem filmagem de um aplicativo Android gráfico.
